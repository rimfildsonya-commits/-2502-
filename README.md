Данная программа была разработана для составления списка покупок на основе рецептв, ингредиентоа, продуктов и диет. Данная программа включает в себя создание ингредиентов, добавление новых ингрелиентов, их меры измерения и количества, а такде комбинирование их в рецепты, масштабирование под порции и сбор списка всех игредиентов для листа покупок, также в проекте можно делать такие операции как умножение количества ингредиента на число, удаление ингредиента, сложение рецептов и тд. Делается с учетом диетических огранический. Проект можно назвать "Лист покупок" или "Shopping list manager".
Для того чтобы установить даннуб программу нужно открыть такую программу как VS Code и написать в строке поиска Terminal: create new terminal снизу откроетсятерминал и туда нужно ввсести следующие команды по порядку:
git clone https://github.com/rimfildsonya-commits/-2502-.git
cd Homeworktp
pip install -r requirements.txt
Чтобы запустить тесты нужно написать также в терминале pytest
